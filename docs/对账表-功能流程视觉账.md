# 对账表-功能流程视觉账（源：e2-reconciliation-v1.md，2026-11-25 收口）

## 三、功能流程视觉账（关键流程逐条视觉核对）

| 流程 | 入口 | 视觉核对结果 |
|---|---|---|
| 登录 → 门禁 | 登录页 | 账号密码登录 → 进入面板，顶栏显示 Admin · 改密码 · 退出 ✅ |
| 改密码（F2） | 顶栏「改密码」 | 弹窗：当前密码 + 新密码（≥8 位）+ 确认；成功后强制重登 ✅ |
| 节点注册/健康 | /dash、/nodes | 空态「暂无数据」正常；节点表列（节点/ID/连接状态/最近在线/注册时间）与原型一致 ✅ |
| 多机批量下发 | /nodes | 批量下发按钮与节点表同页（mock 桥未就绪，交互路径真实）✅ |
| 终端连接 | /term | 节点选择（web-01 (node-01)）+ 连接节点按钮 + 终端区 + 输入行 ✅ |
| 监控曲线 | /monitor | 时间窗切换按钮组（近 1 小时激活态）+ CPU%/内存% 图例 + 进程 Top10 表 ✅ |
| WAF 规则 CRUD | /waf | 新增规则 → 表格启用开关/编辑/删除（Popconfirm）；预览生成配置、导出规则按钮齐备；拦截事件区 ✅ |
| 主机防火墙 + 防篡改 | /fw | 规则变更表单 + 审计表 + 防篡改状态卡 ✅ |
| 用户管理（F1） | /users | 仅 Admin 可见说明条；新增用户（密码仅提交一次、不回显不落审计）；删除不可恢复 ✅ |
| 权限与审计 | /audit | 审计/用户/锁定/安全事件四页签 ✅ |
| 两步验证（TOTP） | /totp | 未启用状态卡 + 生成密钥（需密码复核）+ 规则说明（时钟窗 ±1、连错 5 次锁 5 分钟、恢复码一次性）✅ |
| 备份还原 + 定时策略 | /backup | 备份档案/定时备份策略/发送到其他节点/中转流量统计四区；分片 SHA-256 校验说明条 ✅ |
| 一键迁移 | /migrate | 五步进度条 + 预检/打包/中转/还原（confirm=true）分步表单；环境版本不一致默认拒绝、force 跳过并留审计 ✅ |
| 数据库主从复制 + 外访授权 | /db-replica | 复制状态卡 + 主库创建复制账号（密码仅展示一次）+ 从库配置 + 外访授权表 ✅ |
| Docker 管理 | /docker | 容器表 + 镜像拉取（含加速器仓库提示）✅ |
| 应用一键部署 | /apps | 模板库 + 已部署应用 + 节点未连接时禁用部署并提示 ✅ |
| K8s 集群接入 | /k8s | 接入集群（粘贴 kubeconfig，只存中控、权限 600、绝不下发节点 Agent）+ 连接测试通过才算接入成功 ✅ |
| 网站统计 | /webstats | 解析访问日志（站点 + 日志绝对路径）+ 按日汇总（PV/UV/状态码/流量/Top IP）+ 导出 JSON/清空 ✅ |
| 日志清理 | /logclean | 规则表（路径前缀/大小阈值/年龄阈值）+ 立即清理；gzip 归档保留 7 天、系统目录白名单说明条 ✅ |
| 告警阈值设置（F3） | /settings | 磁盘告警阈值 90% / 恢复阈值 85%；仅 Admin 可保存；阈值即时生效（热重载）、保存留审计 ✅ |
| AI 运维 | /ai | 能力表（日志异常解读/告警处置建议）+ 节点选择 + 生成建议（mock 桥未就绪）✅ |

**结论：21 条关键流程视觉核对全部通过。**
