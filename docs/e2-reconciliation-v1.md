## 五、缺陷记录（本轮实拍发现，零错零警红线）

**WAF 页整页崩溃（已修复）**

- 现象：进入 /waf 整页白屏报错 `Unexpected Application Error! he.some is not a function`（antd Table 内部 `useMemo` 对 `dataSource.some(...)` 崩溃）。
- 根因：后端 `GET /api/waf/rules` 返回包装对象 `{"rules":[],"settings":{...}}`，前端按顶层数组消费并直接传给 Table 的 `dataSource`，非数组即崩。属前后端契约错位，后端测试断言的是包装形状、前端组件测试 mock 的是数组，两侧都"绿"，集成处漏球——正是实拍对账要抓的缺陷。
- 修复：`web/src/pages/Waf.tsx` 的 `load()` 改为解包 `r.rules` / `ev.events`，并加 `Array.isArray` 兜底（契约再变也不会崩）。
- 回归：重建后浏览器实进 /waf 正常渲染（规则表 + 工具栏 + 拦截事件区）；vitest 33/33 复跑通过；其余 28 页截图核对时同步确认无同类错位（12 个按数组消费的端点逐一 curl 核对，顶层均为数组）。
- 教训回灌：**集成契约（包装 vs 顶层数组）必须在前端组件测试里按真实响应形状 mock**；单侧各自为真不等于集成真。已在本表留档。
