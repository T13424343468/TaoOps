## 一、新增需求清单（FR-A11 ~ FR-A21）

### FR-A11 Docker 容器与镜像管理（新模块 docker，P0）
- 要点：容器列表（含状态/端口/镜像/资源占用）、启动/停止/重启、容器日志（走 LogStream 回流，LogControl 增目标类型字段 file|container）、容器终端（term.manage 增 op=attach_container，session_id 路由不变）、镜像列表/拉取/删除；镜像拉取走用户配置的公共源或镜像加速地址（平台侧零投入）。
- 验收口径：
  - 所有操作经中控下发桥并审计留痕；Action 枚举固定 8 类：list/start/stop/restart/logs/terminal/image_list/image_pull/image_remove，审计断言逐类覆盖。
  - 容器名白名单正则 `^[a-zA-Z0-9][a-zA-Z0-9_.-]{0,127}$`；镜像引用正则 `^[a-zA-Z0-9][a-zA-Z0-9._/-]*(:tag)?(@sha256:[a-f0-9]{64})?$`；用户配置的镜像源地址同口径校验。
  - Agent 仅经 /var/run/docker.sock 本地套接字访问，禁止启用 daemon TCP 监听。
  - RBAC：容器终端/删除镜像/删除容器限 Admin；启停限 Operator 及以上（对齐契约 §6）。
  - 日志流断连自动重订；拉取进度可查（层数/字节进度）、失败可重试（重试生成新 request_id 并进审计）。
- 边界：Compose 编排、应用商店、网络与存储卷管理本期不做（下一版）。

### FR-A12 网站访问统计（新模块 webstats，P1）
- 要点：解析 OpenResty/Nginx 访问日志，按站点出 PV/UV/状态码分布/流量/Top 来源 IP 与 URL，日粒度聚合落盘（dataDir/webstats/），面板出趋势图。
- 验收口径：
  - 流式逐行解析（1GB 日志不爆内存，峰值内存 ≤256MB）；单行长度上限 64KB，超长截断不崩溃；日志路径须为绝对路径且拒绝设备文件/管道。
  - UV 定义＝当日去重来源 IP 数，用 HyperLogLog 估算（标准误差 ~2%）；Top-K 用固定容量堆（K≤100），不建全量哈希集合。
  - PV/流量/状态码依赖 nginx 日志字段；用户自定义 log_format 缺 $body_bytes_sent 时降级为仅 PV，边界在面板标注。
  - 日志轮转切割后统计不重不漏（按 inode+偏移断点续读）；统计可按站点/时间范围过滤。
  - 聚合数据默认保留 180 天、可配置；面板提供清空/导出入口（UV/来源 IP 属访问者个人信息）。

### FR-A13 节点间备份（backup 模块扩展，P1）
- 要点：备份目标新增「其他受控节点」，经中控中转（中控只过账不落盘，流式转发）传输到目标节点 BackupDir；完整性校验；还原可跨节点拉回。
- 验收口径：
  - 传输走自有 gRPC 通道，不经任何第三方；大文件中转复用 files 模块 4MB 分片语义（ChunkSize=4<<20、manifest 断点续传），中控侧分片转发；单节点并发转发数=1，中控单流内存缓冲上限 ≤64MB；面板展示中转流量统计。
  - 信任模型：默认中控可见备份明文；PRD 标注该信任边界（源端加密为后续可选项，本期不做）。
  - 目标节点磁盘预检：剩余空间 < 备份包声明大小即拒收并告警（非写满才失败）。
  - 分片级 SHA-256 校验，失败重传该分片并断点续传；整包 SHA-256 仅作最终完整性确认；最终确认失败告警。
  - 还原操作需 confirm=true，还原前自动快照（同 FR-A9 口径）；节点间备份本期仅全量（不继承 FR-A9 增量）。

### FR-A14 一键迁移（新模块 migrate，P1）
- 要点：源节点站点+数据库+环境配置打包（复用 backup 全量逻辑），经中控流式转发到目标节点还原；迁移清单（含版本、路径映射）先行预检。
- 验收口径：还原需 confirm=true；还原前目标节点自动快照（同 FR-A9 口径）；映射源/目标均须绝对路径且规范化后校验，禁止 `..` 与符号链接逃逸；预检失败默认拒绝发起，可 force 跳过且留审计；源/目标环境版本不一致进预检报告，默认拒绝；迁移报告列出成功/跳过/失败明细。

### FR-A15 MySQL 主从复制（db 模块扩展，P2）
- 要点：主从关系配置（主库授权、从库 CHANGE MASTER）、复制状态查询（IO/SQL 线程、延迟）、断链重置。
- 验收口径：变更前备份 my.cnf/配置段（时间戳备份，口径同 FR-A2）；复制账号密码自动生成强随机、仅创建时展示一次不回显，协议 args 中凭据字段在审计与日志统一脱敏；复制中断检测巡检间隔 60s，中断产生面板告警（接 FR-A19，默认级别 warn）；延迟阈值可配置（默认 Seconds_Behind_Master>300 告警）。

### FR-A16 两步验证（auth 模块扩展，P1）
- 要点：TOTP（RFC 6238）绑定（扫码/密钥）、登录二次校验、恢复码（一次性，10 枚）。
- 验收口径：时钟窗 ±1 个 30s 周期；连续 5 次校验失败锁定 5 分钟；恢复码仅存哈希、用后即焚，可重新生成且旧码全部失效；绑定需密码复验；TOTP 密钥落盘权限 600；全程本地算法，无外部依赖。

### FR-A17 日志清理（新模块 logclean，P2）
- 要点：按路径/大小/年龄规则定时清理，命中文件先压缩归档（默认保留 7 天）再删，白名单目录绝对保护。
- 验收口径：
  - 内置默认白名单：/etc、/usr、/bin、dataDir；白名单命中直接拒绝并告警。
  - 清理目标仅限绝对路径，禁止根路径与过宽通配（如 `/*`）；路径匹配语义＝前缀匹配，mtime 按天取整。
  - 每次清理留痕（路径/大小/归档位置）；归档过期自动清理。

### FR-A18 负载均衡（新模块 lb，P1）
- 要点：Nginx upstream 管理（节点增删、权重、健康检查、备用节点），生成 site 配置片段。
- 验收口径：
  - host 校验正则 `^[a-zA-Z0-9._-]+$`（IPv6 括号形式单独口径），端口 1-65535，权重整数范围；配置落盘前 nginx -t 校验，失败不生效并回滚；变更留审计。
  - 健康检查方式 TCP 或 HTTP（建站时二选一）、检查间隔 30s、连续 3 次失败判下线；后端健康状态可在面板查看。
- 边界：lb 仅生成独立 upstream 配置片段，站点引用由用户在 FR-A2 站点管理内自行配置，本期不做站点联动改造。

### FR-A19 面板内告警中心（中控侧模块 alerts，P0）
- 要点：统一告警入口——异常登录（复用入侵检测）、磁盘水位、容器异常（FR-A11）、复制中断（FR-A15）、证书到期（FR-A21）、备份失败（FR-A13）等，面板列表+未读数。告警落盘在 dataDir/alerts/，主要逻辑在中控侧；proto 仅保留「Agent 侧事件上报」子集，不为告警中心另造 Agent 通道。
- 验收口径：
  - 告警落盘可查可过滤；可标记已读；保留策略默认 90 天。
  - 分级映射表（默认值）：磁盘水位 ≥90%=critical、入侵检测 high=critical / medium=warn / low=info、容器异常退出=warn、复制中断=warn、证书到期 ≤30 天=warn、备份失败=warn；分级断言按此表。
  - 验收拆两段：落盘展示先行验收；critical 触发推送（FR-A20）随 FR-A20 落地后补验。

### FR-A20 自定义告警推送（push 页接真，P1）
- 要点：用户自填 webhook URL（钉钉/飞书/企业微信机器人或任意 HTTP 端点），告警触发时 POST JSON 模板；失败重试 3 次，退避间隔 1s/2s/4s。
- 验收口径：
  - URL 仅支持 http(s)；默认禁内网地址——内网段清单：10/8、172.16/12、192.168/16、127/8、169.254/16、0.0.0.0、::1、fc00::/7、fe80::/10，目标域名解析的全部 A/AAAA 记录均不得命中；禁用自动重定向（或每次跳转复检内网判定）。
  - SSRF 白名单由 Admin 角色面板配置、默认为空、变更进审计哈希链。
  - 推送结果留痕：记录时间/URL/状态码/结果，保留策略同告警；平台侧不建任何推送服务。

### FR-A21 SSL 证书自动续期（ssl 页接真，P2）
- 要点：Let's Encrypt ACME（HTTP-01 挑战）签发与自动续期（每日检查，到期前 30 天尝试）；已有证书上传管理、到期提醒（接 FR-A19，默认级别 warn）。
- 验收口径：私钥落盘权限 600；续期失败告警；签发前做 80 端口可达性预检，失败给出明确报错与指引文案；挑战需站点 80 端口公网可达（用户侧有网即可，平台零投入）；自签证书路径保留（离线场景）。
